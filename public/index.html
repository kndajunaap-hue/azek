PRAKTIK PERTAHANAN

Panduan mengamankan website

Langkah dasar untuk mengurangi risiko peretasan, penyalahgunaan akun, dan gangguan layanan.

1. Lindungi akun admin

Gunakan password unik dari password manager, aktifkan MFA yang tahan phishing bila tersedia, hapus akun yang tidak dipakai, dan beri hak akses minimum.

2. Perbarui stack

Perbarui CMS, plugin, tema, framework, runtime, dan dependensi. Hapus komponen yang tidak lagi digunakan; pantau advisori vendor.

3. Perkuat tepi website

Paksa HTTPS, atur security headers, gunakan proteksi DDoS/WAF dan pembatasan request dari penyedia hosting, serta jangan membuka panel admin ke publik tanpa kontrol akses.

4. Jaga rahasia dan data

Simpan token dan password di environment secrets, jangan di folder publik atau Git. Enkripsi data sensitif dan batasi akses ke database.

5. Siapkan pemulihan

Buat backup terpisah dan tidak mudah diubah oleh akun aplikasi. Uji proses restore secara berkala sebelum insiden terjadi.

6. Pantau dan tanggapi

Aktifkan log untuk login dan perubahan admin, buat notifikasi untuk aktivitas aneh, siapkan kontak registrar/hosting, lalu rotasi kredensial dan pulihkan dari backup bersih bila terjadi kompromi.

Rujukan: CISA: sumber keamanan untuk bisnis kecil · CISA: MFA.
